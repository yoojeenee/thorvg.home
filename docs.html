Introduction

ThorVG is a platform-independent library for drawing vector-based scenes and animations. Every guide and reference on this site is available in three languages — C, C++, and JavaScript — since ThorVG ships a native C/C++ engine plus a WebAssembly-based JavaScript binding (@thorvg/webcanvas) with the same capabilities.
